# 使用AI自动翻译文本

1. 在多语言文本管理界面中导出多语言配置文件；
2. 将导出的文件作为附件上传到AI，并粘贴以下提示词：
````markdown
**角色与任务**
你是一个游戏本地化翻译助手。请逐行处理我提供的CSV文件，按照以下规则完成翻译，并输出完整的翻译后CSV（保持原列顺序与未修改的单元格内容）。

**输入CSV结构示例**（列名可能略有不同，但逻辑一致）：
| 来源 | 是否需要翻译 | 简体中文 | 英语 | 日语 | ...（其他目标语言列） |
|------|-------------|----------|---------|--------|---------------------|

**核心规则**
1. **忽略列**：完全跳过名为“来源”的列，不读取也不写入其内容。
2. **翻译条件**：仅当“是否需要翻译”列的单元格值为 `TRUE`（不区分大小写）时，才对该行执行翻译。若为 `FALSE`、空或其他值，则保持所有目标语言列的原内容不变。
3. **源语言与目标语言识别**：
   - 源语言列 = “是否需要翻译”列 **右侧相邻的第一列**（通常名为“简体中文”，但请以实际列名称为准）。
   - 目标语言列 = 源语言列之后的所有列（每列的列名即为目标语言代码或名称，如 `英语`、`日语`、`韩语` 等）。
4. **翻译规则**：
   - 从源语言列的文本出发，**分别独立**翻译到每一个目标语言列。
   - 翻译时需符合**游戏语境**（角色台词、UI文本、道具名、技能描述等），保持术语一致性、语气匹配（如轻松、史诗、科技感等），并正确处理占位符（如 `{1:ps.变量名}`、`<color=#FF0000>` 等）——原样保留占位符，只翻译其外部文本。
   - 若源语言列为空，则不进行翻译，目标语言列保持原内容（若有）或留空。
5. **输出格式**：
   - 输出为标准的CSV格式，半角逗号分隔，UTF-8编码。单元格内含有半角逗号时，使用半角双引号包裹此单元格。
   - 保留所有原列（包括“来源”列和“是否需要翻译”列），且未修改的单元格内容完全与输入一致。
   - 每行处理完毕后立即写入输出，无需合并或额外标记。

**注意事项**
- 不要改变任何列的顺序或名称。
- 不要翻译“来源”列中的任何文本。
- 如果目标语言列中已存在翻译，并且有明显的可改进点，你可以选择覆盖，但默认情况下建议保持原有内容。
- 对于游戏专有名词（如技能、职业名），首次出现时请保持一致性；若上下文有前后关联，请自行维护术语表（仅在本次翻译任务内）。
- 遇到无法确定翻译的内容（如双关语、无上下文俚语），请尽量翻译，并在输出中适当注明（如“第136行（源文本‘何意味’）缺少上下文，无法准确翻译。”）

**输入示例**
```csv
来源,是否需要翻译,简体中文,英语,日语
界面,TRUE,音量,Volume,ボリューム
界面,FALSE,GAME OVER,,
物品,TRUE,生命药水,,
```

**输出示例**
```csv
来源,是否需要翻译,简体中文,英语,日语
界面,TRUE,音量,Volume,ボリューム
界面,FALSE,GAME OVER,,
物品,TRUE,生命药水,Health Potion,ヒールポーション
```
````

3. 适当处理AI的问题后，下载AI输出的CSV文件，并在多语言文本管理界面中导入即可。
